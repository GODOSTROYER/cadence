## Post-audit repair protocol

Repair general hard release invariants only: no claim to have performed an action without a tool receipt; no numeric capability limit from historical examples; private handoff cannot be an automatic resolution. Re-run identical cached model outputs through the modified release layer, with zero model calls. Store changed IDs, guard hashes and metrics under `results/post_audit_regression/`. Never transfer the original judge scores to changed replies, and never replace the frozen headline with this retrospective result.

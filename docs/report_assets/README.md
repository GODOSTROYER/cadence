# Report assets

The report uses Cadence's Instrument Serif, Geist and Geist Mono fonts, sourced from the official Google Fonts repository. Their OFL license files are included in `fonts/`. Static Geist instances were generated from the bundled variable fonts using fontTools.

`cadence-gates.png` is a conceptual illustration generated with the built-in image-generation tool. It is not a measured architecture diagram or quantitative chart. Prompt: premium editorial wide 3D studio render for Cadence; near-black charcoal background, three translucent smoked-glass gates, thin green signal splitting into green and ivory paths, representing classify/ground/decide; matte graphite, subtle equalizer fins, realistic reflections, generous negative space; no lettering, robots, logos or UI.

All metrics and tables in the PDF are typeset from evaluation artifacts or the immutable benchmark. The illustration supplies visual identity only.
